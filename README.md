# Portfolio_IA

Welcome to my **AI Portfolio**. This repository showcases my journey in deep learning, machine learning, and medical imaging, from foundational exercises to advanced projects.

## 📂 Structure

### 00_Foundations
Basic exercises to build solid foundations in PyTorch:
- Regression: approximating simple functions (x², sin)
- Logical gates: AND
- Loss function comparisons for regression: MSE, MAE, SmoothL1, Huber
- Loss function comparisons for classification:BCE , Focal

### 01_Regression
Projects focused on regression problems:
- Linear and polynomial regression
- Regularization techniques (L1, L2)
- Neural network regression examples

### 02_Classification
Classification projects demonstrating neural network concepts:
- Synthetic datasets (Moons, Circles)
- MNIST digits classification
- Decision boundary visualizations

### 03_Clustering
Unsupervised learning projects:
- KMeans clustering
- DBSCAN
- Gaussian Mixture Models
