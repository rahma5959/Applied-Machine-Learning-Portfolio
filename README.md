# Portfolio_IA

Welcome to my **AI Portfolio**. This repository showcases my journey in artificial intelligence, from foundational concepts to advanced projects in deep learning, medical imaging, NLP, and MLOps.

## 📂 Structure

### Learning/
Educational materials and tutorials organized by domain:
- **Deep_Learning/**: Neural networks, architectures, and advanced deep learning concepts
- **Machine_Learning/**: Classical ML algorithms, regression, classification, clustering
- **Computer_Vision/**: Image processing, feature extraction, object detection, segmentation
- **Medical_Imaging/**: DICOM handling, MRI/CT preprocessing, medical image analysis
- **NLP/**: Natural language processing fundamentals and techniques
- **LLMs_and_SLMs/**: Large and small language models, fine-tuning, deployment
- **Statistical_Tests/**: Statistical validation methods (McNemar, bootstrap, etc.)
- **Research_Methodology/**: Experimental design, hypothesis testing, research best practices
- **MLOps/**: Model deployment, monitoring, CI/CD for ML systems

### Research/
Academic and research-oriented work:
- **Publications/**: Published papers and articles
- **Literature_Reviews/**: Comprehensive reviews of AI/ML literature
- **Paper_Reproductions/**: Reproductions of state-of-the-art research papers
- **Research_Notes/**: Research ideas, experiments, and documentation

### Experiments/
Experimental work and benchmarks:
- **Medical_AI_Benchmarks/**: Performance benchmarks on medical AI tasks
- **LLM_Benchmarks/**: Language model evaluations and comparisons
- **Statistical_Validation/**: Statistical validation of model performance
- **Ablation_Studies/**: Ablation studies to understand model components

### Projects/
Complete end-to-end projects:
- **Medical_AI/**: Medical imaging and healthcare AI applications
- **Computer_Vision/**: Computer vision applications and systems
- **LLM_Applications/**: Practical applications of language models
- **RAG_Systems/**: Retrieval-augmented generation implementations
- **AI_Agents/**: Autonomous AI agent systems
- **Multimodal_AI/**: Projects combining multiple modalities (text, image, audio)

### Resources/
Shared resources and utilities:
- **Datasets/**: Dataset links, preprocessing scripts, and documentation
- **Figures/**: Reusable figures, diagrams, and visualizations
- **Templates/**: Code templates and project scaffolds
- **Tutorials/**: External tutorials and learning resources

### Certifications/
Certificates and professional credentials in AI/ML.
