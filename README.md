# AI & Machine Learning Portfolio

Welcome to my AI and Machine Learning portfolio.

I created this repository to document my journey in **Artificial Intelligence, Machine Learning, Deep Learning, Computer Vision, Medical AI, LLMs and MLOps**.

Rather than keeping my work as isolated notebooks or small coding exercises, I use this portfolio to organize what I learn, experiment with different approaches, build practical projects, and document my research-oriented work.

My main goal is simple: **learn by building, experiment by comparing, and improve by understanding the results.**

### 🧪 Experiments

`Experiments/`

This section contains experiments where I focus more on **testing, comparison and scientific evaluation** than on building a final application.

It includes:

* **Ablation Studies** — testing different components of a model to understand what actually contributes to its performance.
* **LLM Benchmarks** — comparing language models and approaches using consistent evaluation criteria.
* **Medical AI Benchmarks** — evaluating AI approaches on medical imaging and healthcare-related tasks.
* **Statistical Validation** — using statistical analysis to determine whether observed improvements are meaningful.

This part of the portfolio represents an important aspect of how I work: I don't want to only ask *"Does the model work?"*, but also *"Why does it work, what improves it, and is the improvement statistically reliable?"*

# 🧠 Deep Learning

`Learning/Deep_Learning/`

This section focuses on Deep Learning architectures and practical model development.
