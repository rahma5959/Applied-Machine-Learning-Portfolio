# Level 04 — Tools

## Overview

This level introduces **tools** into the AI Agent Platform.

A tool is a function that allows an AI Agent to interact with an external capability, such as performing a calculation or retrieving information from an API.

The Agent can analyze a user request and select the appropriate tool.

In this level, the Agent works with:

* Calculator Tool
* REST API Tool
* LLM fallback

---

## Learning Objectives

This level focuses on:

* Understanding the concept of AI Agent tools
* Creating custom tools with LangChain
* Calling tools from an Agent
* Using a REST API from Python
* Routing user requests to different tools
* Understanding tool-based Agent architectures
